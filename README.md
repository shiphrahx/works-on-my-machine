## What's this

Generates billions of plausible-sounding excuses for why your code is broken, so you don't have to admit it was you.

## Features

- 200,611,015,150** possible excuses. That's 13 sentence templates remixing 115 subjects, 89 verbs, 70 states, 181 root causes, and 119 resolutions
- Themes
- Tone slider
- A severity meter
- Shareable links 
- Favourites & history
- Excuse of the day
